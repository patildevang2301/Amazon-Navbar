# Amazon Navbar Clone

## Overview

This project is a simple clone of the Amazon navigation bar created using HTML and CSS. It replicates the basic layout and design of Amazon's top navigation section, including the logo, delivery location, search bar, language selector, account options, orders section, and shopping cart.

## Features

* Amazon logo section
* Delivery location display
* Search bar with category dropdown
* Search icon button
* Language selector (EN)
* Sign In and Account & Lists section
* Returns & Orders section
* Shopping Cart icon
* Responsive layout using HTML structure and CSS styling
* Remix Icons integration for modern icons

## Technologies Used

* HTML5
* CSS3
* Remix Icons CDN

## Project Structure

```
Amazon-Navbar/
```

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Make sure the `amazon.css` file is in the same directory as `index.html`.
4. Open `index.html` in any web browser.
